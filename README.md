# M.A.S Engenharia – Vapor (versão inicial)
Aplicativo estático independente para GitHub Pages.

## Publicar
Crie um repositório público `mas-vapor` no GitHub. Envie `index.html` e `manifest.webmanifest` à raiz do repositório (não a pasta que os contém). Em Settings > Pages, escolha Deploy from a branch, branch `main`, pasta `/ (root)` e salve. Após a publicação, o endereço esperado será `https://ifmequipamentos-boop.github.io/mas-vapor/`, caso o repositório esteja na conta `ifmequipamentos-boop`.

## Aviso
Os cálculos são estimativas educacionais, não substituem dimensionamento executivo ou validação por responsável técnico. O botão PDF usa o diálogo de impressão do navegador (no iOS, selecionar Compartilhar/Salvar em Arquivos como PDF quando disponível).
