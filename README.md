# M.A.S Engenharia – Vapor v3

Aplicativo independente para vapor saturado: tubulações, orifícios e estimativa preliminar de Kv/Cv.

Publique os arquivos na raiz do repositório GitHub Pages. O arquivo `index.html` deve substituir a versão anterior.

**Aviso:** os cálculos são preliminares, não substituem dimensionamento executivo e verificação conforme IEC 60534 e dados do fabricante.
